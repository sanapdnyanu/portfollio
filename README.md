# Portfolio Website

A personal portfolio website showcasing my projects, skills, and contact information.  
This site is built to highlight my work and provide an easy way for people to connect with me.

## 🚀 Features
- **[Home](ca://s?q=Portfolio_home_page)**: Introduction and overview
- **[Projects](ca://s?q=Portfolio_projects_section)**: Showcases my work with descriptions
- **[Skills](ca://s?q=Portfolio_skills_section)**: Technical and professional skills
- **[Contact](ca://s?q=Portfolio_contact_section)**: Easy way to reach me
